## Evidence limitations, gaps, and review needs

- **Candidate-count gap to 13:** none of the five domain pools is below 13 by raw candidate count (the reported count gap is therefore zero in every row). This does not establish evidence sufficiency for a finished instrument: Language, Cognitive, and Social-Emotional still depend on the Phase 5B inventory, and all items need review for suitability, distinctness, and intended use. Gross Motor and Fine Motor have more than 13 source-backed concepts; this is source availability, not evidence that every item should be selected. The product target does not justify filling or trimming a domain by invention.
- **Age gaps:** the supplemental AAP table covers 2?48 months at selected visits; WHO gross-motor windows cover early childhood only (reported windows from 3.8 through 17.6 months). Motor candidates have no new evidence-based checkpoints above 48 months, and fine-motor candidates have none above 48 months. The candidate pool therefore does not establish full 0?72-month age coverage. Existing CDC-derived candidates reach 60 months for nonmotor domains; CDC provides no 72-month checklist.
- **Candidates requiring professional review:** all 47 new motor candidates have `clinical_review_status: pending` and `wording_review_status: pending`; all 48 carried-forward candidates also retain pending wording/clinical review. Review should address AWW observability, local language and cultural/material fit, accessibility, item redundancy, source age interpretation, and whether tasks belong in an AWW-led screening flow.
- **Domain mapping:** the AAP report directly labels separate Gross Motor and Fine Motor columns, so its candidate rows are marked `DIRECT`; this is evidence for category mapping, not for Indian age norms. WHO explicitly supports gross motor only. No WHO/CDC combined Movement/Physical Development category was used to justify fine/gross separation. The ledger retains broader CDC categories as combined.
- **Indian-context limitation:** IAP 2025 is focused on follow-up of high-risk infants, and the TDSC validation record supports an Indian-developed tool but does not expose reusable item-level wording. Neither source justifies extracting TDSC items or claiming SPARSH validation. Confirm tool version and licensing before any future reuse.
- **Concept duplication remains a review task:** the AAP table contains age-progressive observations (for example, object pickup, block construction, and drawing at different ages). They are not collapsed here because the source assigns age-specific behaviors; a pediatric/developmental reviewer should decide whether each adds distinct screening value. No production red flags, weights, scoring thresholds, or diagnostic statements were added.

## Source-backed candidate design notes

Each new record uses a stable Phase 5D identifier, source domain, source age (or WHO source-age range), concise paraphrased observation, source citation, mapping status, and pending clinical/wording/localization review. `sparsh_age_months` repeats the AAP source age only as a provisional source association; it is not a threshold. WHO-only range records leave `sparsh_age_months` null. Every record has `weight: null` and `red_flag: false`. These candidate data are not connected to production screening.
